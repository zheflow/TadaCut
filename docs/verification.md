# 验证与重现

验证以源码版本、运行环境和实际执行范围为准。测试通过不代表所有模型、媒体格式、供应商或操作系统均已验证。

## 2026-10-19 0.2.2 集成检查

高级剪辑、团队服务和 Agent 基础能力已合入正式 TadaCut 仓库，保留公共版本的品牌、数据目录、项目格式和着色器实现。Node 22.22.0 下通过 TypeScript、230 项测试（23 个文件）和生产构建；格式检查通过。构建元数据从 `package.json` 读取版本。

实际 Electron 开发构建通过 42 组流程：全局助手 18 组、高级功能 9 组、原有功能 15 组。记忆流程实际保存和编辑长期偏好与项目约定，任务计划和技能在压缩及页面重载后恢复；外部连接的确认、拒绝和按需工具入口也已覆盖。媒体测试处理小型合成信号，团队测试使用本机 HTTP 服务与独立数据库，录制测试使用 Chromium 虚拟摄像头。27 个效果 / 转场着色器和 11 组颜色边界检查通过。

新增能力与条件见 [高级功能](advanced-features.md)，技能加载、上下文预算、记忆召回、候选确认和中断恢复见 [Agent 基础能力](agent-foundation.md)。自动化中的协议模拟不代表真实付费模型或供应商质量已经验收。浏览器生产页面另通过 20 组流程。

记忆宣传片已实际编码为 1920 × 1080、60 FPS、58 秒的 H.264 / AAC 文件，共 3,480 帧，整段音视频解码无错误。记忆章节展示开启偏好学习后的候选确认和下个项目召回，主文案为“越用，越了解你的习惯”；关键画面已检查。宣传片是工作流程动画，不替代真实应用与模型验证。

`TadaCut-0.2.2-mac-arm64.dmg` 已重新生成。磁盘映像完整性、挂载应用和复制安装后应用的深度签名校验通过，三处 ASAR 哈希一致；从最终映像复制的 App 通过同样 42 组 Electron 流程。安装包包含独立的渲染浏览器与 LGPL FFmpeg，使用本机 ad-hoc 签名，未做 Apple 公证。

云端 Linux 首次执行发现 HDR 转换依赖了旧版 FFmpeg 不支持的浮点 RGB 格式协商。最小画面与回归测试在 2018 年预编译构建上复现了同样错误，现使用兼容的 16 位 RGB 中间格式，最终输出仍为 10 位。新增灰阶回归直接检查 10 位输出的层次、单调性与范围误差，并在旧版和随包 FFmpeg 8.1.3 上验证；素材转换、预览和导出共用同一套滤镜；MOV/MP4 显式写入色彩标记，避免旧版封装器省略 HDR 信息。混音使用旧版兼容的逐声道延时和固定输入长度，回归测试测量长短不同的两条音轨，保证叠加及短音轨结束后的增益不变。完整 HDR 文件、色彩标签、预览与混音链路也已在旧构建上通过。

## 2026-10-18 0.1 发布版本检查

TadaCut 品牌版本已通过 TypeScript、183 项自动化测试（15 个文件）、格式检查与生产构建；20 项浏览器流程和 30 项 Electron 流程通过。27 个效果 / 转场着色器在真实 WebGL2 中编译与链接成功，11 组 HSV 颜色边界及随机纹理的分布、变化和可重复性检查通过。

宣传片实际编码为 1920 × 1080、60 FPS、50 秒 H.264 / AAC 文件，并通过整段解码检查。工作台截图来自该版本的实际页面。

当日公共 npm 源审计结果为 0 high、0 critical、15 moderate。剩余条目主要来自可选桌面自动化依赖的 Jimp / file-type，以及 Electron 下载和打包工具依赖链。它们仍需跟踪升级；没有把自动化检查当成无漏洞保证。

## 环境

使用 Node 22.22.0 或更新的 Node 22 LTS，以及 npm 10。主要验证平台为 macOS arm64。测试创建独立临时数据目录，使用原创画面与合成音频。

```sh
npm ci
npm run check
npm test
npm run format:check
npm run build
npm run test:ui
npm run test:shaders
```

## 覆盖范围

- 领域与 API：命令校验、修订冲突、事务、撤销重做、片段编辑、字幕映射、故事同步、工程往返、任务与供应商协议。
- 安全边界：公开接口不返回密钥；模型不能自行放宽权限或改变已存密钥的发送地址；发布确认不能通过任务重跑绕过。
- 浏览器：生产构建的真实页面、时间线拖动、检查器、素材、导出、对话与持久化。
- Electron：全局助手、多选引用、跨轨拖动、页面上下文、应用管理、扩展、主题与窄窗口布局。
- GLSL：真实 WebGL2 编译与链接、HSV 颜色边界、随机纹理的范围、分布和可重复性。

本机 UI 报告写入 `evidence/`，不进入公开仓库。接口测试使用受控 HTTP 服务与协议样本；测试替身不代表对应云端服务已经验收。

## 桌面验证

```sh
node scripts/smoke-assistant-ui.mjs
TADACUT_TEST_MOCK_KEYCHAIN=1 node scripts/smoke-features-ui.mjs
```

Electron 自动化使用隔离 profile 与测试钥匙串，避免测试阻塞于系统凭据授权。正常启动不启用该测试开关。钥匙串、屏幕、麦克风和辅助功能权限由使用者自行授权。

已安装且登录的外部运行时可以单独诊断：

```sh
node scripts/check-real-codex.mjs
```

脚本检查可执行文件、协议握手与认证，不提交模型推理。检测结果不等同于配额或推理质量保证。

## 宣传片

`npm run promo` 实际编码宣传片与合成配乐，输出到 `output/promo/`。它验证该宣传片的渲染链路，不覆盖编辑器所有素材组合的导出。宣传片中的工作流由动画呈现，README 的截图来自实际应用。

## 已知验证边界

- Windows 安装包的构建任务已配置，尚未在 Windows 设备运行验收。
- 在线生成和第三方发布依赖用户账号与服务条件，未对所有供应商做真实付费调用。
- Whisper、CLAP、DETR 的权重下载与推理需要主动运行；入口和协议测试不等同于模型质量测试。
- 个人桌面录制和跨应用操作依赖原生权限，自动化测试不操作个人应用。
- 本地 macOS 打包使用 ad-hoc 签名，公开分发前须配置签名与公证。
