# TadaCut 高级功能

这些功能由本项目独立实现，全部提供界面入口和具体对话工具。项目修改仍经过版本检查和统一事务；耗时任务产出候选结果，应用时再次检查输入依赖。改变过的片段不会被旧任务覆盖，应用结果可以撤销。

## 使用条件与边界

- AI 抠像、视频消除、超分、数字人、口型同步和歌词识别需要配置相应供应商。程序调用真实接口、下载真实结果，未配置时返回不可用原因。自动化验证只测试协议契约，没有调用付费推理，模型输出质量与时延需用自己的服务实际试片。
- 人像调整是对指定区域进行磨皮、亮度与形变；当前区域和眼睛位置由用户或助手指定，不宣称已经做了自动人脸关键点检测。
- 本机跟踪采用纹理匹配和四点透视解算。遮挡、低纹理和快速位移可能导致低置信度；任务结果会提示检查，不会把失踪帧伪装成可靠跟踪。
- 速度曲线的视频时间映射使用精确积分，音频使用细分时段的保音高拉伸；剧烈曲线仍建议试听。
- 基础剪辑序列可以保留源 HDR 高光并导出 10 位 H.265/ProRes。复杂画面效果、文字、蒙版、重叠图层等采用现有 SDR 渲染器；必须显式接受“允许 SDR 特效合成”后才能转换到目标 HDR 空间。这会压缩源 HDR 高光。色彩转换确实改变像素和色域，不是仅写标签。HDR 转换结果同时生成 SDR 预览代理。
- ASS 的字体、颜色、文本、卡拉 OK 时间可导入；未支持的 ASS 绘图、定位及动画指令会给出提示。无逐词时间的 LRC 使用明确标注的估算高亮；模型转写使用返回的真实词时间戳。
- 预渲染按片段缓存，可以包含图片、视频、标题、代码动画和嵌套序列；保留图层混合关系，参数或依赖变化后不会复用旧结果。生成整段预渲染文件未作为例行自动化验证项目。
- 团队目录是用户自建服务中实际发布的内容，初始目录为空；没有虚构公共素材数量或社区。评审链接固定在创建时的版本，支持过期和撤销。下载历史版本会创建一个新本地项目。

## 团队服务

应用内“团队与共享素材 → 连接”可以启动本机服务。默认仅本机可连接；勾选“允许局域网连接”后，其他设备用此电脑 IP 和所设端口连接。管理员在“成员”创建独立访问凭据，并对项目授予只读或编辑权限。访问凭据保存在本机加密凭据库，对话查询只返回是否配置。

也可以在自己的服务器运行：

```sh
# 先设置至少 24 字符的 TADACUT_TEAM_ADMIN_TOKEN。
# TADACUT_TEAM_DATA 指定数据目录，TADACUT_TEAM_HOST / PORT 指定监听地址。
npm run team:dev
# 生产构建后：
npm run team:start
```

服务默认绑定 `127.0.0.1:4399`。远程部署应使用 HTTPS 入口。团队数据、版本、成员散列凭据和文件存放在独立数据目录；不需要访问桌面版的本机项目数据库或模型密钥。
