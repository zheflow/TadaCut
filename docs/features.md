# 功能覆盖

TadaCut 采用自己的数据模型、界面和实现。代码存在、契约测试和本机运行验证分别说明，不把远端接口适配等同于真实账号已测试。

## 剪辑与生产

| 能力                               | TadaCut 实现 / 页面                                                                                                           | 条件与边界                                                                                         |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| 工程、多时间线、跨项目素材复用     | SQLite 项目、活动时间线、素材库                                                                                               | `.tadacut` 携带工程与本地素材；浏览器 / 桌面宿主数据目录独立                                       |
| 导入、去重、元信息与缩略图         | 哈希去重、FFprobe、FFmpeg                                                                                                     | 文件保存在本机；视频是否预览由 Chromium 解码能力决定                                               |
| 文件夹自动导入与素材重连           | 桌面目录选择、递归监听、重连保持 assetId                                                                                      | 只监控用户选定目录，每轮扫描最多 3000 条目，单文件上限 512 MB                                      |
| 素材理解与语义检索                 | 视觉模型取样、文本 embedding、CLAP 标签                                                                                       | 视频视觉理解取样 3 帧；embedding 可接本地 Ollama                                                   |
| 多轨、切割、修剪、波纹删除、编组   | 时间线拖动与键盘、刀片工具（B）、命令引擎                                                                                     | 锁定轨道拒绝相关编辑；编辑经过 revision 校验                                                       |
| 专业剪辑工具                       | 滑移（Y）、滑动（U）、卷动（N）、插入 / 覆盖、关闭空隙、复制、链接、同步锁定、嵌套序列                                        | 每个操作由领域规划函数生成一次事务、一步撤销；同步锁定轨道无法保持对齐时拒绝并说明原因             |
| 标记、版本与回收站                 | 标记颜色 / 备注 / 范围；项目版本快照；回收站与复制项目                                                                        | 恢复版本是可撤销的编辑并保留项目名称；永久删除只在回收站中进行，连同版本、对话和导出记录           |
| 变速、定位、缩放、旋转、适配       | 片段属性与 Stage                                                                                                              | 浏览器预览的极端速度受 HTMLMediaElement 限制；导出按指定速度处理                                   |
| 统一撤销、重做与联合事务           | 领域克隆校验 + SQLite 事务                                                                                                    | 分镜和时间线同步一项撤销；幂等 requestId；撤销快照压缩保存，每个项目保留最近 200 步                |
| 通用关键帧与 easing                | X/Y/scale/scaleX/scaleY/rotation/opacity/volume/focusX/Y/圆角                                                                 | 线性、缓入、缓出、缓入缓出、保持与贝塞尔曲线（带曲线预览和预设）                                   |
| 画面布局与水印                     | 画中画、左右 / 上下分屏、三栏、四宫格、九宫格；文字或图片水印                                                                 | 布局按选择顺序排入；水印随导出渲染                                                                 |
| 点击驱动聚焦                       | 会话点击记录、focusFromClicks、片段属性                                                                                       | 记录来自应用会话执行的点击；不是全系统鼠标监听                                                     |
| 竖屏 / 多画幅重构                  | 复制为 9:16、1:1、4:5、16:9 新时间线；可选本地 DETR 主体跟随                                                                  | 原时间线不变；位置按比例换算，文字按短边保持大小；主体按裁切窗口居中并平滑，每个视频最多采样 12 帧 |
| 播放、穿梭与入出点                 | J/K/L 倍速穿梭、逐帧、剪辑点跳转、I/O 入出点、循环播放                                                                        | 入出点按时间线保存在本机界面偏好；倒放时画面逐帧定位、不出声                                       |
| 标题、字幕与字幕样式               | 文字素材、字幕轨、SRT；命名样式、动效、逐词高亮、翻译、平台安全区                                                             | 字幕按剪辑后的入点、速度和词时间戳映射；翻译保留原文，逐词动效在译文上退为整行动画                 |
| 字幕与图形避开人物                 | 本机 DETR 人物检测、字幕上移、图形移到空白处                                                                                  | 按画面所在源帧检测，假定该画面铺满画幅；检测模型首次使用时下载                                     |
| 本地 / 云端词级转写                | Whisper Worker、供应商 multipart 转写                                                                                         | 本地模型首用下载；服务需返回词级时间戳                                                             |
| 文稿删词、去口癖、文字修正与说话人 | 文稿页面、transcript.cut/set/speaker；查找替换、停顿压缩、播放高亮                                                            | 删词产生源时间范围剪辑；不通过音频猜测台词；跨词替换合并为一个词并保持时间对齐                     |
| 波形、轨道混音、静音与音量动画     | 真 PCM 波形、WebAudio gain、Remotion Audio                                                                                    | 音频关键帧与淡入淡出参与混音                                                                       |
| 响度归一、静音、节拍与声音语义     | FFmpeg loudnorm、RMS、onset/autocorrelation、CLAP                                                                             | 静音为能量阈值算法；节拍显示置信度，未使用 BeatThis / 神经 VAD                                     |
| 人声降噪与分离                     | 本机高低通与 afftdn；供应商人声分离                                                                                           | 本机只处理底噪；分离人声与音乐需要支持的服务（如 ElevenLabs）                                      |
| 配乐闪避与卡点                     | 说话时压低配乐、剪辑点对齐节拍、随节拍排图、按小节剪短配乐                                                                    | 节拍来自本机分析并缓存；说话时段来自文稿或对白 / 旁白轨道                                          |
| 场景切换与高光                     | FFmpeg 场景分数、按语速 / 情绪词 / 响度打分                                                                                   | 场景结果可分割或标记；高光可做范围标记或生成精华版新时间线                                         |
| AI 配音、音色克隆与音乐            | OpenAI 兼容 / ElevenLabs / 自定义路由                                                                                         | 使用用户配置服务；克隆需拥有相应录音的使用权                                                       |
| 图片 / 视频 / 音效生成             | 图片生成与编辑、参考图生视频、音效、封面、任务轮询与再生成                                                                    | 已确认角色 / 场景参考图可传给支持的服务；fal 队列地址只允许在所配置的域名内                        |
| 转场与特效                         | 着色器转场库、参数化 WebGL 特效、镜头运动预设                                                                                 | 转场保存在前一个片段上；扩展包可添加 GLSL 转场与特效                                               |
| 调色、LUT、色阶、RGB 与抠像        | CSS 基础调色、WebGL2 3D LUT、Lift/Gamma/Gain、亮度 / 色度抠像；原创风格库                                                     | 自动平衡是取样像素的初始方案；示波器与风格对比用与导出相同的渲染取帧                               |
| 自定义 shader                      | GLSL ES 300 编辑与 WebGL2 运行                                                                                                | shader ABI 和错误在预览中体现；失败时保留源画面                                                    |
| 代码动画、模板与素材池             | 独立 React 动画、原创模板、AI 生成与代码编辑                                                                                  | 沙箱只开放 React 和 frame/fps/width/height                                                         |
| 剧本、角色、场景、道具、分镜       | 故事开发、分集分场、剧本表、实体特征 / 音色 / 三视图、候选图                                                                  | 所选模型决定创作与生成能力；支持从时间线整理分镜                                                   |
| 分镜批量生产                       | 分镜图 → 视频 → 配音三阶段，指纹判断缺失与过期，历史可恢复                                                                    | 每阶段可选不同服务；分镜图失败的镜头不生成视频；可选生产后排到时间线                               |
| 双向同步、冲突与生产绑定           | 独立同步基线、联合历史、生成时检查分镜指纹                                                                                    | 生成期间分镜变化时保存素材，并提示用户手动绑定                                                     |
| 创作画布                           | 持久化笔记与分镜 / 素材节点，拖动位置                                                                                         | 当前连接表达分镜顺序；没有通用 DAG 调度器                                                          |
| 多机位同步与切换                   | 音频相关性、持久化机位组、切换点、主音轨                                                                                      | 低相关性拒绝自动同步；NDF 时间码由源元信息提供                                                     |
| 录屏、系统音、麦克风与旁白         | MediaRecorder、原生来源选择、WebAudio 混音                                                                                    | 依赖平台的捕获权限与系统音支持                                                                     |
| 受约束应用操作与 Computer Use      | 目标窗口会话、截图、点击、输入、有限键和滚动                                                                                  | 辅助功能和屏幕权限；视觉模型由用户指定；单次任务最多 25 动作                                       |
| 共享预览 / 渲染                    | Stage、动画 / 效果采样与预构建 Remotion Composition                                                                           | 预览使用 HTML5 视频（含倒放与倍速穿梭）；导出由 OffthreadVideo 经 FFmpeg 取精确帧                  |
| 视频、音频、透明导出               | H.264/H.265/VP8/VP9/ProRes；MP3/WAV；入点到出点；所选片段；当前帧图片                                                         | 本次验证不实际编码成片；透明限 WebM / ProRes                                                       |
| 导出记录、校验、上传与发布         | ffprobe 对照时长、分辨率与音轨；S3 兼容存储限时链接；Upload-Post 发布                                                         | 发布须在对话框中确认，Agent 的发布永远逐次确认；云存储与发布使用用户自己的服务                     |
| 工程、字幕与 NLE 交换              | `.tadacut`、SRT、Markdown、FCPXML、CMX EDL、CapCut ZIP                                                                        | 外部格式的复杂效果 / MG 需媒体化；CapCut 模板需目标版本复核                                        |
| 后台任务、取消、恢复与重试         | 持久化队列、SSE、AbortSignal、重启中断标记                                                                                    | 入队导出冻结快照；重启不自动重发收费任务                                                           |
| 界面外观                           | 默认白色浅色（中性灰分层、蓝色标出操作重点、红色只用于错误）/ 墨绿深色 / 跟随系统；樱花装饰可选；应用图标与安装映像为白粉配色 | 桌面版原生菜单与窗口背景同步；预览画面与导出不受影响                                               |
| 渲染资源与并发                     | 构建时预打包、任务并发 2、帧渲染并发默认取 CPU 逻辑核心的一半（1–8 可调）                                                     | 按分辨率与本机内存下调渲染线程；Mac 上 WebGL 效果走 ANGLE（GPU）；硬件编码取决于本机               |
| 素材整理与在线素材                 | 文件夹筛选、重命名、标签、描述；Pexels / Pixabay / Freesound；网址导入                                                        | 在线素材记录来源、作者与许可；下载限公开地址与媒体类型                                             |
| 扩展包与字体                       | `tadacut-plugin@1`：模板、LUT、音效、转场、特效、镜头运动、字幕样式                                                           | 扩展只提供资源；模板代码禁止联网与引入模块；音效复制进项目后与扩展无关                             |

## 全局助手

右侧助手贯穿全部 8 个主页面；页面、故事与资源子页、筛选和多项引用自动进入上下文。182 个工具包含 44 个应用管理工具，覆盖模型公开配置、技能、扩展、任务与设置。API 与 App 内外部运行时共享权限策略；具体能力与必须由用户完成的本机交互见 [assistant.md](assistant.md)。素材支持多选引用与批量拖入，多个片段可跨同类轨道拖动，显示落点并可一次撤销。

## 当前验证级别

截至 2026-10-18，功能与连接诊断累计通过 183 项自动化测试（15 个文件）。全局助手版本通过类型与格式检查、生产构建、20 项浏览器流程和 30 项真实 Electron 界面流程；重新打包后的 Mac 应用也用临时 profile 和测试钥匙串复验了这 30 项流程，未批准系统钥匙串授权。扩展安装、资源使用与移除已实际操作；场景检测只验证无素材状态，封面等远端功能验证表单与服务选择，人物避让只检查入口。规则、预置资源、协议 mock 和真实验证的区别见 [reality-audit.md](reality-audit.md)。

本机执行已覆盖工作台、编辑与撤销、提案确认、供应商配置和模型发现的模拟服务、分镜同步、代码动画、工程 ZIP、CapCut 草稿生成、原生模块加载和 Mac 启动。远端生成、神经模型推理质量、第三方应用实际操作、Windows 运行与真实成片编码不属于本次已验证范围。精确记录见 [verification.md](verification.md)。
