# Agent 基础能力

这些能力是 TadaCut 创作助手的基础设施，适用于整个 App。Skill 定义工作流程，Tool 执行具体动作；对话、工作记录和长期记忆各自持久保存。完整工具目录保留在宿主，按需提供给模型。

| 能力               | 实现与入口                                                                                                     | 主要验证                                       |
| ------------------ | -------------------------------------------------------------------------------------------------------------- | ---------------------------------------------- |
| 技能发现与加载     | `read_skills`、`load_skill`；正文分页，参考资料通过 `read_skill_file` 分页读取                                 | 目录、分页和真实工具协议                       |
| 技能生命周期       | 独立保存最近 3 个技能及已读文件位置，压缩与重启后恢复；内容指纹变化提示重载；`unload_skill` 或上下文面板卸载   | 改动失效、重载、卸载、数量边界                 |
| 工具按需加载       | API 初始 12 个定义，搜索后保留有限工作集合；外部连接仅传 8 个入口                                              | 目录体积、分组不全量展开、权限检查             |
| 任务计划与工作笔记 | `read_agent_state`、`update_agent_plan` 保存目标、约束、步骤、待办与笔记；按 revision 防止旧计划覆盖新内容     | 项目隔离、版本冲突、重启与压缩恢复             |
| 上下文管理         | 自动预算检查、主动压缩、保留当前要求和未完成工具调用、摘要失败兜底；预算默认 24,000，可在设置改为 8,000–64,000 | 单轮长任务、待确认调用、系统与工具定义计入预算 |
| 主动压缩           | 助手顶部“管理上下文 → 压缩旧对话”；`request_context_compaction` 安排下一次应用请求前压缩                       | 不改项目、计划与长期记忆，运行中拒绝界面压缩   |
| 会话与中断恢复     | 消息和工具结果落库，保留连接类型、模型、模式及状态；失败或停止后可继续                                         | CLI 协议进程失败后继续、重启后的历史传递       |
| 项目与长期记忆     | `remember`、`search_memories`、`list_memories`、`forget`、`consolidate_memories`；设置页搜索、添加、编辑、删除 | 相关性召回、去重、并发保护、合并事务           |
| 偏好学习           | 默认关闭；启用后产生候选，经用户接受才保存；拒绝和重复接受不会新增偏好                                         | 候选确认、去重、密钥格式拦截                   |
| 工具与任务执行     | 类型化参数、宿主权限、任务状态、等待与取消、错误信息、有限重试；应用状态必须以实际回执为准                     | API、权限、后台任务、外部协议测试              |
| 修改与验收         | 手动模式先形成草稿，确认后应用；统一版本检查与撤销；可开启完成后自查                                           | 草稿冲突、权限确认、一次撤销                   |
| 限定的技能子代理   | `skill_subagent` 用独立模型上下文完成拆分任务，共享本轮草稿；限制能力与嵌套层数                                | 权限与宿主工具约束；需配置可用对话模型         |
| 可观察性           | 工具过程、任务计划、技能、上下文预算与压缩次数均可查看；累计用量单独显示                                       | Electron 实际界面流程                          |

## 使用方式

助手顶部的“管理上下文”显示当前计划、工作笔记、已加载技能和连接。可以主动压缩旧对话、卸载不再需要的技能，或跳到记忆设置。新对话清空本次任务记录与技能引用，长期偏好和项目约定保留。

可以直接说：“先列一个剪辑计划”“加载声音与歌词技能”“记住我偏好白色字幕”“这条约定只用于当前项目”“删除刚才那条偏好”“压缩旧上下文，保留现在的任务”。工具权限和应用模式仍适用于这些操作。

任务计划的“完成”状态是助手记录，不能代替实际工具结果。中断后，对于结果未知的工具调用，不自动盲目重放；助手先读取项目、后台任务与草稿，核对哪些修改已生效。

## 边界

- 工作记录和技能正文在每次 API 模型请求前重新读取；长正文受独立体积限制，会标明后续读取位置。参考文件保存已读位置，细节可按需重新读取。
- 记忆召回采用关键词相关性和时间排序。摘要可能损失细节，用户当前要求优先于历史记忆，真实项目状态优先于摘要。
- 应用输入预算采用估算，不等同于供应商计费。外部 CLI 单次运行中的内部压缩由对应运行时管理；应用负责进入 CLI 前的历史与工具定义。
- 自动学习默认关闭。API 学习可能额外调用模型；外部 CLI 通过 `suggest_memory` 提出候选。密钥留在凭据库，不能通过记忆接口存储常见格式的密钥。
- 不把未经执行的模型输出算作验证成功。自动化验证使用本机协议模拟与隔离数据，没有调用付费推理。

实现位于 `apps/server/src/agent.ts`、`agent-state.ts`、`agent-memory.ts`、`agent-tools/session.ts` 和 `packages/agent/src/`。主要验收为 `tests/agent-foundation.test.ts`、`tests/agent-context*.test.ts`、`tests/agent-runner.test.ts` 与 `scripts/smoke-assistant-ui.mjs`。
