# 功能真实性核查

核查日期：2026-10-16；源码、隔离数据下的实际界面操作和真实 CLI 诊断分别记录。测试通过只能证明相应测试覆盖的行为，不能证明所有供应商、模型质量、平台兼容性和成片输出已经验证。

## 外部运行时连接

应用实际启动已安装的 CLI 或 SDK，并使用本机已有登录状态。检测可执行文件、协议握手、认证状态与模型推理是不同步骤，界面分别显示结果。缺少运行时、登录过期、网络或代理错误会显示具体原因，不返回固定成功消息。

显式 `TADACUT_CODEX_PATH` 配置优先；支持 nvm / fnm / mise 等常见路径布局。连接检查不提交模型回合，也不将邮箱或凭据返回界面。认证协议见 [App Server 文档](https://learn.chatgpt.com/docs/app-server#auth-endpoints)。

在 macOS 开发环境中，真实 Codex 已通过连接诊断和一次最小对话。该结果不代表其他账号、代理、CLI 版本或服务配额可用。Claude 与 Copilot 的完整真实账号流程尚未验收。

## 记忆与上下文

项目约定和长期偏好真实持久化，可搜索、编辑和删除。自动学习默认关闭，启用后只产生候选，经用户确认才保存；明确要求“记住”也可以直接保存。召回使用关键词相关性与时间排序，当前要求优先；不宣称能无误理解每个习惯。任务工作记录、已加载技能和聊天压缩摘要分开保存，具体预算与生命周期见 [Agent 基础能力](agent-foundation.md)。

## 已纠正的误导状态

- “请安装并登录 CLI”改为区分未找到 CLI、已找到但未验证、需要登录、协议连接失败、握手与认证检查通过。
- Copilot 的 `installed` 原先只检查 SDK 模块存在；现在直接说明“SDK 已安装；本机运行时与登录尚未验证”。
- 外部 Agent 的用量原先用 `0 / 0` 占位；现在读取运行时报告，没有报告时存为 `null`，显示“运行时未提供用量”。报告为零与未知严格区分。
  旧对话已经保存的占位零不能当作实测用量；未改写用户历史数据。普通 API 对话在服务未报告用量时采用明确标注“约”的估算。
- 供应商“检测连接”只读取模型目录，现在显示“模型目录可读”，并说明尚未验证推理。目录可读也不保证某个模型支持图片、视频或工具调用。
- 高光入口改为“按语速、关键词和响度推荐高光候选”。
- API 模型没有返回文字时，原来兜底显示“完成。”；现在说明模型没有返回文字，提示检查工具记录与修改预览，不据此宣告任务成功。
- 任务百分比部分来自阶段里程碑，例如开始连接、下载、登记；不是精确的剩余时间或每帧实测进度。

## 测试里的 mock 在哪里

`scripts/smoke-assistant-ui.mjs` 使用本机脚本模型和显式绑定的 Codex 协议替身，验证工具循环、权限确认、SSE、上下文与界面实际改动。它不验证真实 Codex 账号。`tests/runtime-status.test.ts` 使用临时可执行协议样本，验证诊断分支与隐私约束。供应商测试用本机 HTTP 服务返回受控响应。

Electron 验证使用独立临时数据库、profile 与 `--use-mock-keychain`，避免阻塞在 macOS 的系统钥匙串授权。这个测试开关不在应用正常启动参数中，不替代真实系统授权。测试的假账号、回复和资源不写入用户数据库。

`scripts/check-real-codex.mjs` 另用真实 CLI、最小 PATH、禁用登录 shell 的隔离应用进行连接诊断；仍使用测试钥匙串，但不模拟 Codex。报告和截图分别为 `evidence/desktop-real-codex.*` 与 `evidence/packaged-real-codex.*`。这与模拟协议的界面测试是不同证据。
